# Night Shift: Laundromat

**Systems horror, no jump scares.** You run a 24-hour laundromat, 11pm to 6am, in a town where the regulars are… off. Manage machines, stock and power while the horror emerges from the systems themselves: a cycle that finished itself, a log entry with no one on camera, and a rule sheet that gains a new rule every night.

Free on Google Play (nights 1–3) with a one-time $4.99 unlock. No ads, no consumables, fully offline.
